# Glossary

**Accuracy** — the fraction of all predictions that are correct. Useful only alongside a baseline and a breakdown of mistakes.

**Actuator** — the part of a machine that changes the world: a motor, a wheel, a heater, a display.

**Admissible heuristic** — a guess at the cost still to go that never overestimates the truth. Required if A-star is to return the shortest path.

**Agent** — anything that senses its environment and acts on it.

**AI effect** — the habit of calling a solved problem “not really artificial intelligence” once it works.

**A-star** — a search that orders possibilities by the cost already paid plus the estimated cost still to come.

**Base rate** — how common a condition is in the population, before any evidence is considered.

**Baseline** — the score a deliberately simple method achieves. The bar that intelligence must clear.

**Bias** — a systematic error that disadvantages a group or a situation; also, in statistics, the difference between an estimate and the truth.

**Breadth-first search** — exploring in rings, nearest first; finds the shortest path and uses a great deal of memory.

**Calibration** — the agreement between a stated confidence and the observed frequency of being right.

**Classification** — predicting which category an example belongs to.

**Concept drift** — a change in the relationship between inputs and outputs, so that a model that was right becomes wrong.

**Confusion matrix** — a table of predictions against true labels, showing the two kinds of mistake separately.

**Convolution** — a small filter slid across an image or signal, producing a map of where its pattern occurs.

**Cross-validation** — training and testing several times on different splits, so that every case is used for both.

**Data drift** — live data slowly diverging from the data a model was trained on.

**Depth-first search** — following one branch to its end before trying another; low memory, no guarantee of a short path.

**Distribution shift** — any difference between the data a model was trained on and the data it meets in use.

**Embedding** — a list of numbers representing a word or token, positioned so that similar meanings are close together.

**Error budget** — the mistakes a system is allowed to make, specified by type.

**Expert system** — a program holding a specialist's rules, used in medicine, configuration and industry from the 1970s.

**Feature** — a measurable input used by a model.

**Forward chaining** — deriving conclusions from known facts by applying rules until nothing new appears.

**Generalisation** — doing well on cases the model has never seen.

**Heuristic** — an estimate or rule of thumb that guides a search without guaranteeing an answer.

**Inference** — in logic, deriving new facts from known ones; in machine learning, using a trained model to produce an output.

**Knowledge base** — the store of facts and rules in a rule-based system.

**Label** — the answer a supervised model is trained to predict.

**Leakage** — information about the test set, or about the future, accidentally present in the training data.

**Loss** — a single number scoring how wrong a set of predictions is. Smaller is better.

**Mean absolute error** — the average size of the errors, ignoring sign.

**Mean squared error** — the average of the squared errors; punishes large misses heavily.

**Narrow intelligence** — a system good at one task and helpless outside it.

**Nearest neighbour** — predicting by copying the label of the most similar known example.

**Overfitting** — fitting the training examples so closely that new examples fail.

**Percept** — one reading of the environment.

**Pixel** — one small square of an image, holding a brightness or colour value.

**Policy** — an agent's rule for choosing an action from what it knows.

**Precision** — of the cases a system flagged, the fraction that were correct.

**Prior** — a belief held before new evidence is considered.

**Recall** — of the real cases, the fraction the system found.

**Regularisation** — any penalty on model complexity intended to improve generalisation.

**Reinforcement learning** — learning a policy by trial, error and reward.

**Sensitivity** — of the cases that are really positive, the fraction a test detects.

**Sensor fusion** — combining several sources of evidence into one belief.

**Spectrogram** — a picture of sound, showing energy at each frequency over time.

**Supervised learning** — learning from labelled examples.

**Threshold** — a cut-off that turns a number into a decision.

**Token** — a small unit of text, usually a word or part of a word.

**Training set** — the examples a model learns from.

**Transformer** — a network architecture built on attention, introduced in 2017 and now dominant in language processing.
