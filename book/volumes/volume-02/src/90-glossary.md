# Glossary

**Absolute encoder** — a sensor that reports the full joint angle at every reading, without needing a reference position.

**Actuator** — the part of a machine that changes the world; in this volume, usually a motor.

**Backlash** — the small free movement between gear teeth before the output begins to turn.

**Ball screw** — a screw transmission using recirculating balls, with high efficiency and low backlash.

**Bill of materials** — the list of every part in a build, with quantities and costs.

**Brushless motor** — a motor with electronic commutation instead of brushes; efficient, durable and dependent on a driver.

**Cantilever** — a beam fixed at one end and free at the other; the basic model of a robot link.

**C-rate** — the multiple of a battery's capacity at which it can be discharged.

**Dead reckoning** — estimating position by integrating measured motion, without an external reference.

**Degrees of freedom** — the number of independent motions a mechanism can make.

**Differential drive** — a mobile robot driven by two independently powered wheels.

**Duty cycle** — the fraction of time a machine or signal is active; for motors, the fraction of time a load may be applied.

**Encoder** — a sensor that reports rotation as a series of counts.

**End effector** — the tool at the end of a robot arm: a gripper, a welder, a camera.

**Frame** — a coordinate system attached to a part of the machine.

**Gear ratio** — the ratio of input turns to output turns in a transmission.

**H-bridge** — four switches arranged to drive a motor in both directions.

**Harmonic drive** — a compact, high-ratio, near-zero-backlash transmission used in robot joints.

**Inertial measurement unit** — a sensor package reporting acceleration and angular rate.

**Joint** — a connection between links that permits some relative motion.

**Kinematic chain** — the sequence of links and joints from base to tool.

**Lead screw** — a screw that converts rotation into linear motion at a fixed advance per turn.

**Nyquist criterion** — the rule that a signal must be sampled at more than twice its highest frequency.

**Open-loop control** — control without feedback: the command is issued and not checked.

**Payload** — the mass a robot can carry at its tool, usually specified at a given reach.

**PWM** — pulse width modulation; rapid switching used to control average voltage.

**Parallel mechanism** — a mechanism connecting base and platform through several chains at once.

**Prismatic joint** — a joint that allows sliding along one axis.

**Proportional control** — a controller whose output is proportional to the error.

**Repeatability** — the ability to return to the same point; distinct from accuracy.

**Resolution** — the smallest change an instrument or actuator can report or produce.

**Revolute joint** — a joint that allows rotation about one axis.

**Risk assessment** — a structured evaluation of hazards by severity and likelihood.

**Serial mechanism** — a mechanism whose links form a single chain from base to tool.

**Servo** — a motor with position feedback and a controller that holds a commanded position.

**Shunt resistor** — a low-value resistor used to measure current.

**Stepper motor** — a motor that moves in fixed increments and holds position without feedback.

**Stiffness** — resistance to deflection under load; distinct from strength.

**Subsumption** — an architecture in which higher-priority behaviours suppress lower-priority ones.

**Teleoperation** — direct human control of a remote or hazardous machine.

**Torque** — a turning force, measured in newton-metres.

**Workspace** — the set of positions a robot's tool can reach.

**Watt-hour** — a unit of energy: one watt supplied for one hour.
